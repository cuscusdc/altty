O Cargo do Kazzu declara MIT no workspace. O README histórico apresenta GPL; essa divergência exige decisão dos titulares antes de uma redistribuição. Foi retirada a afirmação categórica sobre o próprio aplicativo em Sobre. Os avisos de dependências continuam separados. Para estas alterações, a separação entre observação de comportamento e escrita original evita adicionar uma nova obrigação por código portado. A análise cobre a proveniência desta intervenção; os recursos históricos e o licenciamento efetivo da distribuição Slint exigem revisão própria.

A equipe não incorporou SF Symbols, SF Pro, telas, marcas, material promocional, gravações ou imagens da Apple. Inter e a iconografia existentes continuam no pacote. As capas são as retornadas pela biblioteca e pelos provedores.
